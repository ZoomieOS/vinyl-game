# Виниловая рулетка 🎵

Небольшая интерактивная страница-подарок: партнёр крутит виниловую пластинку, она случайно
останавливается на одном из восьми музыкальных жанров (дрим-поп, лоу-фай, пост-панк,
соул/фанк, латино-альт, электроника, джаз и старый добрый Меладзе) и выдаёт нишевый трек
вместе с лёгким комплиментом, обыгрывающим его настроение или название. У каждого трека есть
кнопка со ссылкой на поиск в Spotify.

Сделано не как массовое приложение, а для одного конкретного человека.

## Что внутри

- `index.html` — самодостаточная страница: вся вёрстка, стили и логика в одном файле,
  внешние зависимости — только шрифты Google Fonts (Cormorant Garamond, Manrope).
- Адаптивная вёрстка (от ~360px до десктопа), поддержка светлой и тёмной темы устройства.
- Колесо жанров на CSS `conic-gradient`, анимация вращения с точным попаданием на сектор.
- Комплименты и переворот карточки трека не повторяются, пока не закончится колода жанра.

## Как посмотреть

Просто открыть `index.html` в браузере — сборка и сервер не нужны:

```bash
open index.html         # macOS
xdg-open index.html     # Linux
```

Либо поднять любой статический сервер, например:

```bash
python3 -m http.server 8000
```

и зайти на `http://localhost:8000`.

## Редактирование

Все треки и комплименты лежат в объекте `pools` внутри `<script>` в `index.html` —
можно менять жанры, добавлять треки или переписывать комплименты, не трогая остальную
вёрстку.
